PROJECT INFORMATION
──────────────────────
Tên dự án: Language Quiz Chatbot
Phiên bản: 1.0 (Complete)

MÔ TẢ
──────
Ứng dụng chatbot Python để kiểm tra khả năng tiếng Anh, 
Tiếng Trung, Tiếng Nhật với chấm điểm tự động (0-100), 
cho phép sửa lỗi, gợi ý thông minh, và thống kê chi tiết.

TÍNH NĂNG CHÍNH
────────────────
✓ 3 ngôn ngữ: Tiếng Anh, Tiếng Trung, Tiếng Nhật
✓ 3 loại kiểm tra: Meaning, Example, Vietnamese
✓ Lựa chọn linh hoạt: 5/10/15/20 câu hoặc tất cả
✓ Chấm điểm tự động: 0-100, xếp loại A-F
✓ Cho phép sửa lỗi: Tối đa 3 lần mỗi câu
✓ Gợi ý thông minh: Hint & Show Answer
✓ Thống kê chi tiết: Tổng, trung bình, phân tích
✓ Thêm dữ liệu: Từ file Excel
✓ Tính năng nâng cao: Optional (phát âm, ôn từ yếu, v.v.)

CÀI ĐẶT
────────
1. Cài Python 3.8+ từ python.org
2. Mở Command Prompt/Terminal
3. cd d:\Da Ngon Ngu\language_quiz_app
4. pip install -r requirements.txt (nếu cần)
5. python main.py (hoặc nhấp run.bat)

CÁCH CHẠY
──────────
Windows:
  • Cách 1: Nhấp đúp run.bat
  • Cách 2: python main.py
  • Cách 3: VS Code → F5

Linux/Mac:
  • chmod +x run.sh && ./run.sh
  • python3 main.py

CÁCH THÊM DỮ LIỆU
──────────────────
1. Chuẩn bị file Excel (4 cột: word, meaning, ex_en, ex_vi)
2. python excel_to_json.py
3. Nhập tên file Excel
4. Nhập tên file JSON output
5. Chạy lại main.py

THANG ĐIỂM
──────────
Mỗi câu (0-10):
  10 đ: Lần 1 đúng
   8 đ: Lần 1 gần đúng
   7 đ: Lần 2 đúng
   5 đ: Lần 2 gần đúng
   4 đ: Lần 3 đúng
   0 đ: Sai

Tổng (0-100):
  90-100: A (Xuất sắc)
  80-89: B (Tốt)
  70-79: C (Khá)
  60-69: D (Đạt)
  < 60: F (Chưa đạt)

CÁCH SỬ DỤNG
─────────────
1. Chạy main.py
2. Chọn ngôn ngữ (1-3)
3. Chọn loại kiểm tra (1-3)
4. Chọn số câu (1-5)
5. Trả lời từng câu
6. Xem kết quả

PHÍM TẮT
─────────
Trong kiểm tra:
  • [Enter] = Gửi câu trả lời
  • h = Gợi ý (hint)
  • c = Xem đáp án (correct answer)

Menu:
  • c = Tiếp tục
  • n = Thoát
