📋 HƯỚNG DẪN CỤ THỂ - GUI
═══════════════════════════════════════════════════════════════

BẠN 1: CHUẨN BỊ
───────────────

1. Chạy: python gui_main.py
   ↓ Cửa sổ GUI mở lên
   ↓ Tab "📋 Chuẩn bị" hiển thị

2. Nhấp: "📁 Chọn File Excel..."
   ↓ Hộp thoại mở lên

3. Chọn file Excel
   Option 1: Dùng template
     • Tạo trước: python create_templates.py
     • Chọn: TEMPLATE_ENGLISH.xlsx
   
   Option 2: File của bạn
     • Format chuẩn 4 cột (Word, Meaning, Ex EN, Ex VI)
     • Chọn file

4. Chọn Sheet (nếu file có nhiều sheet)
   • GUI hiển thị danh sách sheet
   • Chọn sheet muốn kiểm tra

5. Cấu hình kiểm tra
   • Loại: Meaning / Example / Vietnamese
   • Số câu: 5 / 10 / 15 / 20 / Tất cả

6. Nhấp: "▶️ BẮT ĐẦU KIỂM TRA"
   ↓ Chuyển sang tab "🎯 Kiểm tra"


BẠN 2: KIỂM TRA
─────────────

Tab "🎯 Kiểm tra" xuất hiện:

Hiển thị:
  • Tiến độ: [████░░░░░] 3/10 (30%)
  • Câu hỏi: Câu hỏi lớn dễ đọc
  • Hộp trả lời: Nhập câu trả lời

Hành động:
  • Nhập đáp án + nhấn Enter/Gửi
    ↓ Nếu đúng → Chuyển câu tiếp (tự động sau 2 giây)
    ↓ Nếu sai → Cho phép sửa lại (tối đa 3 lần)

  • Nhấp "💬 Gợi Ý" → Xem hint
    VD: "cô, ***"

  • Nhấp "👁️ Xem Đáp Án" → Xem đáp án
    (Bạn được 0 điểm, tự động qua câu tiếp)

Feedback:
  ✓ "✓ Đúng! Bạn được 10 điểm"
  ~ "~ Gần đúng, hãy thử lại (Lần 2/3)"
  ✗ "✗ Sai. Đáp án là: cô, dì"


BẠN 3: XEM KẾT QUẢ
──────────────────

Tab "📊 Kết quả" tự động mở:

Hiển thị:
  ════════════════════════════════
  📊 KẾT QUẢ KIỂM TRA
  ════════════════════════════════
  Tổng điểm: 42/50
  Điểm trung bình: 84/100
  Xếp loại: B - Tốt
  ════════════════════════════════
  
  CHI TIẾT KẾT QUẢ:
  
  Câu 1
    Câu hỏi: Từ 'aunt' có nghĩa là gì?
    Trả lời: cô
    Đáp án: cô, dì
    Điểm: 10/10
  
  Câu 2
    Câu hỏi: Từ 'love' có nghĩa là gì?
    Trả lời: yêu
    Đáp án: yêu, thích
    Điểm: 8/10
  
  (tiếp tục với các câu khác...)

Nút hành động:
  • "💾 Lưu Kết Quả" → Lưu JSON
  • "🔄 Kiểm Tra Lại" → Quay về bước 1


═══════════════════════════════════════════════════════════════
📝 FORMAT FILE EXCEL CHUẨN
═══════════════════════════════════════════════════════════════

BẮTU BUỘC - Hàng 1 (Header):
┌─────────┬──────────┬────────────┬────────────┐
│ Word    │ Meaning  │ Example EN │ Example VI │
└─────────┴──────────┴────────────┴────────────┘

Dữ liệu - Từ hàng 2 trở đi:
┌─────────┬──────────┬────────────┬────────────┐
│ aunt    │ cô, dì   │ Is she your aunt? │ Cô ấy là cô? │
│ love    │ yêu      │ Do you love it? │ Bạn yêu không? │
│ white   │ màu trắng│ Is it white? │ Nó trắng không? │
│ help    │ giúp đỡ  │ Can you help? │ Giúp được không? │
│ (tiếp) │          │           │          │
└─────────┴──────────┴────────────┴────────────┘

Nguyên tắc:
  ✓ Hàng 1 là header
  ✓ Không để ô trống trong cột A (Word)
  ✓ Dữ liệu dày đặc (không dòng trống)
  ✓ Lưu dạng .xlsx (Excel 2016+)
  
  ✗ Không dùng .xls (Excel 2003)
  ✗ Không để ô trống trong cột quan trọng

✅ KIỂM TRA TRƯỚC CHẠY GUI

□ Python 3.8+ cài chưa?
  → python --version

□ tkinter cài chưa?
  → Thường cài sẵn với Python
  → Windows: Nếu lỗi, cài lại Python (chọn tcl/tk)
  → Linux: sudo apt-get install python3-tk
  → Mac: Cài Python từ python.org

□ openpyxl cài chưa?
  → pip install openpyxl

□ File gui_main.py tồn tại?
□ Thư mục data/ tồn tại?

💡 MẸOVỚI GUI
═══════════════════════════════════════════════════════════════

1. Phím tắt
   → Enter = Gửi câu trả lời

   → Window mặc định 900x700 px
   → Có thể resize

🆘 KHẮC PHỤC LỖI
═══════════════════════════════════════════════════════════════

❌ "ModuleNotFoundError: tkinter"
✅ → Windows: Cài lại Python (chọn tcl/tk)
✅ → Linux: sudo apt-get install python3-tk
✅ → Mac: Cài Python từ python.org

❌ Cửa sổ GUI không xuất hiện
✅ → Chạy từ terminal: python gui_main.py
✅ → Xem error trong console
✅ → Kiểm tra antivirus

❌ Không chọn được file
✅ → Kiểm tra file .xlsx (không .xls)
✅ → Kiểm tra đường dẫn (không ký tự lạ)
✅ → Thử file khác

❌ "Excel file seems to be binary"
✅ → Lưu file Excel dạng .xlsx
✅ → Không dùng .xls

❌ Template không tạo được
✅ → Chạy: python create_templates.py
✅ → Kiểm tra quyền thư mục data/
