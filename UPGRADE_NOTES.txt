📊 GUI - HƯỚNG DẪN BƯỚC TỪng BƯỚC
════════════════════════════════════════════════════════════════════════════════

BẠN 1: LÀM quen với GUI
────────────────────────

1. Chạy: python gui_main.py
   ↓
2. Tab "📋 Chuẩn bị" xuất hiện
   • Nhấp: "📁 Chọn File Excel..."
   • Chọn: TEMPLATE_ENGLISH.xlsx
   ↓
3. Chọn sheet (Sheet mặc định là "English H2")
   ↓
4. Chọn loại kiểm tra:
   ○ Meaning (ý nghĩa)
   ○ Example (dịch ví dụ)
   ○ Vietnamese (dịch từ Việt)
   ↓
5. Chọn số câu: 5 hoặc 10
   ↓
6. Nhấp: "▶️ BẮT ĐẦU KIỂM TRA"


BẠN 2: KIỂM TRA
─────────────

Tab "🎯 Kiểm tra" xuất hiện

Hiển thị:
  • Tiến độ: ███░░░░░░  1/10
  • Câu hỏi: "Từ 'aunt' có nghĩa là gì?"
  • Hộp trả lời: (nhập câu trả lời ở đây)

Hành động:
  • Nhập đáp án, nhấn Enter
    ↓ Nếu đúng → Chuyển câu tiếp
    ↓ Nếu sai → Cho phép sửa (tối đa 3 lần)
  
  • Nút "💬 Gợi Ý" → Xem hint
    (VD: "cô, ***")
  
  • Nút "👁️ Xem Đáp Án" → Xem đáp án
    (Bạn được 0 điểm)

Feedback:
  • "✓ Đúng! Bạn được 10 điểm"
  • "~ Gần đúng, thử lại"
  • "✗ Sai. Đáp án là: cô, dì"


BẠN 3: XEM KẾT QUẢ
──────────────────

Tab "📊 Kết quả" xuất hiện

Hiển thị:
  ════════════════════════════════
  📊 KẾT QUẢ KIỂM TRA
  ════════════════════════════════
  Tổng điểm: 42/50
  Điểm trung bình: 84/100
  Xếp loại: B - Tốt
  
  CHI TIẾT KẾT QUẢ:
  ────────────────
  Câu 1
    Câu hỏi: Từ 'aunt'...
    Trả lời: cô
    Đáp án: cô, dì
    Điểm: 10/10
  ...

Nút hành động:
  • "💾 Lưu Kết Quả" → Lưu JSON
  • "🔄 Kiểm Tra Lại" → Quay về bước 1

📝 FORMAT FILE EXCEL CẤP
════════════════════════════════════════════════════════════════════════════════

Hàng 1 - HEADER (Bắt buộc):
┌──────────┬────────────┬────────────┬────────────┐
│ Word     │ Meaning    │ Example EN │ Example VI │
└──────────┴────────────┴────────────┴────────────┘

Hàng 2+ - DỮ LIỆU:
┌──────────┬────────────┬────────────┬──────────────────┐
│ aunt     │ cô, dì     │ Is she your aunt? │ Cô ấy là cô? │
│ love     │ yêu, thích │ Do you love? │ Bạn có yêu không? │
│ white    │ màu trắng  │ Is it white? │ Nó có trắng? │
│ (tiếp...)│            │            │                │
└──────────┴────────────┴────────────┴──────────────────┘

Lưu ý:
  ✓ Hàng 1 là header (Word, Meaning, Example EN, Example VI)
  ✓ Dữ liệu từ hàng 2 trở đi
  ✓ Không để ô trống trong cột A (Word)
  ✓ Lưu dạng .xlsx (Excel 2016+)
  ✗ Không dùng .xls (Excel 2003)
  ✗ Không để dòng trống giữa dữ liệu

════════════════════════════════════════════════════════════════════════════════
🆘 TROUBLESHOOTING - GUI
════════════════════════════════════════════════════════════════════════════════

❌ "No module named tkinter"
✅ Giải pháp:
   • Windows: Cài lại Python (chọn "tcl/tk" during installation)
   • Linux: sudo apt-get install python3-tk
   • Mac: Cài Python từ python.org (bao gồm tkinter)

❌ GUI không mở lên
✅ Giải pháp:
   • Chạy từ terminal: python gui_main.py (xem error)
   • Kiểm tra antivirus
   • Thử chạy với Python mới nhất

❌ Không chọn được file Excel
✅ Giải pháp:
   • Kiểm tra file tồn tại
   • Kiểm tra đường dẫn (không ký tự lạ)
   • Lưu file dưới .xlsx

❌ Hộp trả lời không focused
✅ Giải pháp:
   • Nhấp vào hộp trả lời
   • Hoặc nhấn Tab để focus

❌ Kết quả không lưu được
✅ Giải pháp:
   • Chọn vị trí lưu hợp lệ
   • Kiểm tra quyền thư mục
   • Thử lưu vào Desktop

💡 TƯ VẤN VỀ THIẾT KỀ
════════════════════════════════════════════════════════════════════════════════

Nếu bạn muốn tùy chỉnh GUI thêm:

1. Thay đổi kích thước cửa sơ:
   root.geometry("900x700")
   → Thay thành: root.geometry("1000x800")

2. Thay đổi màu sắc:
   self.root.configure(bg="#f0f0f0")
   → Thay thành màu khác

3. Thêm/xóa nút:
   Tìm: ttk.Button(...)
   Edit theo ý muốn

4. Thay đổi font chữ:
   Tìm: font=("Arial", 12)
   Thay thành font khác
