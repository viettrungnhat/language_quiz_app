🔍 HOW DETECTION WORKS
────────────────────────────────────────────────────────────

1. Read Headers
   A1, B1, C1, D1
   Compare with TEMPLATE headers

2. Check Structure (if not TEMPLATE)
   Column B: Meaning, Word, Meaning, Word... (alternating)
   Column D: Example VI, Example EN, Example VI, Example EN...

3. Detect Language
   Scan Column B Row 2 (word) for:
   ├─ Hiragana/Katakana/Kanji → Japanese
   ├─ Hanzi → Chinese
   ├─ ASCII → English
   └─ Vietnamese characters → Vietnamese

4. Calculate Confidence
   ├─ Structure + Language = 95%
   └─ Structure only = 85%

5. Make Decision
   If convertible & not TEMPLATE:
      Show user dialog with results
   Else:
      Load file as-is

❓ FAQ
────────────────────────────────────────────────────────────

Q: Why isn't my file detected as convertible?
A: Check if file has alternating structure:
   Row 1: Meaning, Row 2: Word, Row 3: Meaning, Row 4: Word...

Q: Can I reject the conversion?
A: Yes! Click NO in the dialog to use original file.

Q: Is my original file modified?
A: No! Conversion creates *_template.xlsx (new file).

Q: What languages are supported?
A: Japanese (95%), Chinese (95%), English (85%), Vietnamese (90%)

Q: How long does conversion take?
A: < 2 seconds for typical files (100-200 rows)

Q: What if conversion fails?
A: Original file loads anyway (may have errors)
   Check FILE_CONVERTER_GUIDE.md troubleshooting section
