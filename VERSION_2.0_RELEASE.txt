🎤 CÔNG NGHỆ GIỌNG NÓI

TEXT-TO-SPEECH (TTS):
   Library: pyttsx3
   Hỗ trợ: Offline (không cần internet)
   Tính năng: Phát audio từ text
   Hỗ trợ: English, Chinese, Japanese, Vietnamese

SPEECH-TO-TEXT (STT):
   Library: SpeechRecognition + Google
   Hỗ trợ: Online (cần internet)
   Tính năng: Chuyển âm thanh → text
   Độ chính xác: ~95% (tùy tiếng nói)

MICROPHONE:
   Library: pyaudio
   Hỗ trợ: Ghi âm từ microphone
   Yêu cầu: Microphone kết nối

🔄 QUY TRÌNH KIỂM TRA GIỌNG NÓI

1. BẮT ĐẦU:
   Chọn file Excel → Cấu hình → "KIỂM TRA GIỌNG NÓI"

2. HIỂN THỊ CÂU HỎI:
   ├─ Hiển thị text: ❓ What does 'book' mean?
   ├─ Phát âm: "What does book mean?" (TTS)
   └─ Chờ bạn nói

3. LẮNG NGHE:
   ├─ Nhấn "🎤 NGHE GIỌNG NÓI"
   ├─ Chờ bạn nói (max 15 giây)
   └─ Ghi âm + gửi Google

4. NHẬN DẠNG:
   ├─ Google nhận dạng → "a written work"
   ├─ Hiển thị: 🎤 Bạn nói: a written work
   └─ Chuyển về

5. SO SÁNH:
   ├─ Đáp án đúng: "a published set of pages"
   ├─ So sánh độ tương đồng
   └─ Điểm: 7/10 (70% tương đồng)

6. FEEDBACK:
   ├─ ⚠️ Khá! Độ chính xác 70%
   ├─ Đáp án đúng: a published set of pages
   ├─ Điểm: 7/10
   └─ Tự động chuyển câu tiếp theo (sau 2 giây)

7. LẶP LẠI:
   Quay lại bước 2 cho câu hỏi tiếp theo

8. KẾT THÚC:
   Sau câu cuối cùng → Tự động hiển thị kết quả

═══════════════════════════════════════════════════════════════════════════════

📊 CHẤM ĐIỂM

Dựa trên độ tương đồng (Sequence Matching):

   100% tương đồng    → 10/10 ✅ Chính xác
   80-99%              → 8-10 ✅ Tốt
   70-79%              → 5-7 ⚠️  Khá
   50-69%              → 2-4 ❌ Yếu
   <50%                → 0 ❌ Sai

Điểm tổng = (Tổng từ tất cả câu) / (Số câu)

⚙️ CẤU HÌNH

Chỉnh các thông số trong voice_quiz.py:

# TỐC ĐỘ NÓI:
self.tts_engine.setProperty('rate', 150)
   150 = tốc độ bình thường
   100-130 = chậm hơn
   170-200 = nhanh hơn

# ÂM LƯỢNG:
self.tts_engine.setProperty('volume', 0.9)
   0.9 = 90% (bình thường)
   0.5 = 50% (nhỏ)
   1.0 = 100% (to)

# NGƯỠNG ÂM THANH MICROPHONE:
self.recognizer.energy_threshold = 4000
   Cao hơn → bỏ qua tiếng nền nhiều
   Thấp hơn → nhạy cảm hơn

🆘 TROUBLESHOOTING

❌ "ModuleNotFoundError: pyttsx3"
   → pip install pyttsx3

❌ "ModuleNotFoundError: speech_recognition"
   → pip install SpeechRecognition

❌ "ModuleNotFoundError: pyaudio"
   → pip install pyaudio
   → Nếu Windows: Tải .whl file (xem VOICE_QUIZ_GUIDE.txt)

❌ "Lỗi microphone"
   → Kiểm tra Windows Settings → Sound
   → Microphone kết nối chưa?

❌ "Không nhận dạng được giọng nói"
   → Nói rõ ràng hơn
   → Kiểm tra kết nối internet (Google STT cần internet)

❌ "Máy không phát âm"
   → Kiểm tra loa bật chưa?
   → Kiểm tra âm lượng Windows

❌ "Không có internet → STT không hoạt động"
   → Điều đó bình thường (Google STT cần internet)
   → Có thể dùng TTS (phát âm) mà không cần internet
