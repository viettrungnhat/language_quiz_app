📊 THANG ĐIỂM & XẾOP LOẠI
════════════════════════════════════════════════════════════════════════════════

ĐIỂM MỖI CÂU (0-10):
  10 điểm: Lần 1 trả lời đúng chính xác
   8 điểm: Lần 1 trả lời gần đúng
   7 điểm: Lần 2 trả lời đúng
   5 điểm: Lần 2 trả lời gần đúng
   4 điểm: Lần 3 trả lời đúng
   0 điểm: Sai hoàn toàn

ĐIỂM KIỂM TRA (0-100):
  Công thức: (Tổng điểm / (Số câu × 10)) × 100

  Ví dụ: 5 câu, điểm 10+9+7+8+8 = 42
         42 / (5 × 10) × 100 = 84/100

XẾP LOẠI:
  A - Xuất sắc   (90-100%)
  B - Tốt        (80-89%)
  C - Khá        (70-79%)
  D - Đạt        (60-69%)
  F - Chưa đạt   (< 60%)

🔧 THÊM DỮ LIỆU TỪ FILE EXCEL
════════════════════════════════════════════════════════════════════════════════

Nếu bạn có file Excel như "H3 trung phần 2":

Bước 1: Chuẩn bị file Excel với 4 cột
  │ A      │ B           │ C            │ D          │
  │ word   │ meaning     │ example_en   │ example_vi │
  │────────┼─────────────┼──────────────┼────────────│
  │ aunt   │ cô, dì      │ Is she...?   │ Cô ấy...?  │
  │ love   │ yêu, thích  │ Do you...?   │ Bạn có...? │

Bước 2: Chạy excel_to_json.py
  → python excel_to_json.py
  → Nhập tên file Excel
  → Nhập tên file JSON output

Bước 3: Chạy lại main.py
  → Dữ liệu mới xuất hiện trong menu!

Chi tiết: Xem EXCEL_GUIDE.txt

🆘 KHẮC PHỤC LỖI
════════════════════════════════════════════════════════════════════════════════

Lỗi: ModuleNotFoundError: No module named 'openpyxl'
→ Giải pháp: pip install openpyxl

Lỗi: 'python' is not recognized
→ Giải pháp: Cài Python từ python.org (chọn "Add Python to PATH")

Lỗi: File not found
→ Giải pháp: Kiểm tra đường dẫn & tên file (chính tả)

Lỗi: Encoding error (ký tự lạ)
→ Giải pháp: Lưu file Excel UTF-8, dùng Python 3.8+
