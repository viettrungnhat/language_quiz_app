📋 QUY TRÌNH LẦN ĐẦU
━━━━━━━━━━━━━━━━━━

1) Chương trình hiện menu ngôn ngữ:
   Chọn: 1 (Tiếng Anh) / 2 (Trung) / 3 (Nhật)
   → Gõ: 1 [Enter]

2) Chọn loại kiểm tra:
   1 = Hỏi ý nghĩa
   2 = Dịch ví dụ
   3 = Dịch Việt sang Anh
   → Gõ: 1 [Enter]

3) Chọn số câu:
   1 = 5 câu
   2 = 10 câu
   3 = 15 câu
   4 = 20 câu
   5 = Tất cả
   → Gõ: 1 [Enter]

4) Trả lời câu hỏi:
   Ví dụ: "Từ 'aunt' có nghĩa là gì?"
   → Gõ: cô, dì [Enter]
   
   Hoặc:
   → Gõ: h [Enter] (xem gợi ý)
   → Gõ: c [Enter] (xem đáp án)

5) Xem kết quả:
   ✓ Điểm từng câu
   ✓ Tổng điểm & xếp loại
   ✓ Chi tiết từng câu

6) Tiếp tục hay không?
   Gõ: c [Enter] (tiếp tục)
   Gõ: n [Enter] (thoát)

💡 TIPS NGAY LẦN ĐẦU
━━━━━━━━━━━━━━━━

  → Được 10 điểm thay vì 7-8 điểm

Tip 2: Nếu sai, xem gợi ý trước
  → Gõ: h [Enter]

Tip 3: Nếu còn sai, xem đáp án
  → Gõ: c [Enter]

Tip 4: Ôn lại sau 1 tuần
  → Từ sai lần đầu thường dễ nhớ hơn

Tip 5: Bắt đầu với 5 câu
  → Sau khi quen, tăng lên 10-20 câu


📖 THÊM DỮ LIỆU CỦA BẠN
━━━━━━━━━━━━━━━━━━━━━

Nếu bạn có file Excel (H3 trung, anh, v.v.):

Bước 1: Chuẩn bị file Excel
  Cột A: word (từ)
  Cột B: meaning (ý nghĩa Việt)
  Cột C: example_en (ví dụ tiếng Anh)
  Cột D: example_vi (ví dụ tiếng Việt)

Bước 2: Chạy python excel_to_json.py
  → Script sẽ hỏi tên file Excel
  → Script sẽ hỏi tên file JSON output

Bước 3: Chạy lại python main.py
  → Dữ liệu mới xuất hiện trong menu!

Chi tiết: Xem EXCEL_GUIDE.txt
