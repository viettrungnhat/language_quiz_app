🔧 CÔNG NGHỆ

Module "voice_quiz.py":
   
   TTS (Text-to-Speech):
   ├─ Library: pyttsx3
   ├─ Hoạt động: Offline (không cần internet)
   ├─ Tính năng: Phát âm text thành audio
   └─ Hỗ trợ: English, Vietnamese, Chinese, Japanese

   STT (Speech-to-Text):
   ├─ Library: SpeechRecognition + Google
   ├─ Hoạt động: Online (cần internet)
   ├─ Tính năng: Chuyển audio thành text
   └─ Độ chính xác: ~95%

   Microphone:
   ├─ Library: pyaudio
   ├─ Hoạt động: Ghi âm từ input
   ├─ Yêu cầu: Microphone kết nối
   └─ Tính năng: Capture audio

GUI Thread Management:
   ├─ _speak_question() → Chạy trên thread riêng (không block GUI)
   ├─ _voice_listen_thread() → Xử lý STT trên thread riêng
   └─ root.after() → Cập nhật GUI thread-safe

So Sánh Thông Minh:
   ├─ SequenceMatcher (difflib) → Tính độ tương đồng
   ├─ Word-level matching → Kiểm tra từng từ
   └─ Threshold-based scoring → 70% = điểm, <70% = sai

📊 CHẤM ĐIỂM VOICE QUIZ

Công thức:
   
   Độ tương đồng = Compare(câu trả lời người dùng, đáp án đúng)
   
   100% → 10 điểm    ✅ Chính xác 100%
   80-99% → 8-10    ✅ Tốt
   70-79% → 5-7     ⚠️  Khá
   50-69% → 2-4     ❌ Yếu
   <50% → 0         ❌ Sai

Ví dụ:
   Đáp án: "a book is a written work"
   Bạn: "a written work of fiction"
   Độ tương đồng: 75% → Điểm: 6/10

⚙️ CẤU HÌNH

Trong voice_quiz.py, có thể chỉnh:

1. Tốc độ nói (rate):
   self.tts_engine.setProperty('rate', 150)
   150 = bình thường, 100 = chậm, 200 = nhanh

2. Âm lượng (volume):
   self.tts_engine.setProperty('volume', 0.9)
   0.9 = 90%, 0.5 = 50%, 1.0 = 100%

3. Ngưỡng âm thanh (energy_threshold):
   self.recognizer.energy_threshold = 4000
   Cao = bỏ tiếng nền nhiều, Thấp = nhạy hơn
