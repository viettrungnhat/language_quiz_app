🔧 CÁC MODULE:

voice_quiz_v2.py:
   - VoiceManager
     ├─ speak_google_tts(text, language) ← Google TTS online
     ├─ listen_to_microphone(timeout, language) ← Google STT
     └─ Hỗ trợ: English, Vietnamese, Chinese, Japanese
   
   - VoiceQuizManager
     ├─ ask_question_voice(text, language, repeat=2) ← Hỏi 2 lần + lắng nghe
     └─ compare_answers(user_ans, correct_ans) ← So sánh

gui_main_v2.py:
   - voice_display_question() → Hiển thị + phát câu hỏi
   - _speak_question() → Đọc 2 lần + tự động lắng nghe
   - _voice_listen_thread() → Xử lý STT + scoring

📞 TROUBLESHOOTING:

Q: "ModuleNotFoundError: gtts"
A: pip install gtts

Q: "Không có âm thanh"
A: • Kiểm tra loa/headphone
   • Kiểm tra âm lượng Windows
   • Cần kết nối internet

Q: "Không nhận dạng giọng nói"
A: • Nói rõ ràng hơn
   • Kiểm tra microphone
   • Kiểm tra internet (Google Speech cần online)

Q: "Lỗi: [Errno 32512]"
A: Pygame playback issue
   Solution: Hệ thống sẽ fallback để phát file audio
