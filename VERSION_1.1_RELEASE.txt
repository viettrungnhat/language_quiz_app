════════════════════════════════════════════════════════════════════════════════
📋 HƯỚNG DẪN BẮTĐẦU - GUI
════════════════════════════════════════════════════════════════════════════════

BƯỚC 1: Chuẩn bị
  1. python create_templates.py  (Tạo file template)
     → Tạo 3 file: TEMPLATE_*.xlsx trong data/
  
  2. (Tuỳ chọn) Sửa template
     → Mở file TEMPLATE_ENGLISH.xlsx
     → Sửa/thêm dữ liệu
     → Lưu file

BƯỚC 2: Chạy GUI
  python gui_main.py
  → Cửa sổ GUI mở lên

BƯỚC 3: Chuẩn bị kiểm tra (Tab 1)
  1. Nhấp: "📁 Chọn File Excel..."
     → Chọn TEMPLATE_ENGLISH.xlsx (hoặc file bạn)
  
  2. Chọn sheet (nếu có)
  
  3. Chọn loại kiểm tra:
     ○ Meaning - Ý nghĩa
     ○ Example - Dịch ví dụ
     ○ Vietnamese - Dịch từ Việt
  
  4. Chọn số câu: 5, 10, 15, 20, Tất cả
  
  5. Nhấp: "▶️ BẮT ĐẦU KIỂM TRA"

BƯỚC 4: Kiểm tra (Tab 2)
  1. Xem tiến độ: ████░░░░░ 3/10
  2. Đọc câu hỏi
  3. Nhập trả lời + Enter
  4. Xem feedback
  5. Sửa lại nếu sai (tối đa 3 lần)
  6. Tự động chuyển sang câu tiếp

BƯỚC 5: Xem kết quả (Tab 3)
  1. Tổng điểm: 42/50
  2. Điểm trung bình: 84/100
  3. Xếp loại: B - Tốt
  4. Chi tiết từng câu
  5. Nhấp "💾 Lưu Kết Quả" để lưu JSON

📝 FORMAT FILE EXCEL CHUẨN
════════════════════════════════════════════════════════════════════════════════

HÀNG 1 - HEADER (Bắt buộc):
┌──────────┬────────────┬────────────┬────────────┐
│ Word     │ Meaning    │ Example EN │ Example VI │
└──────────┴────────────┴────────────┴────────────┘

HÀNG 2+ - DỮ LIỆU:
┌──────────┬────────────┬────────────┬────────────────────┐
│ aunt     │ cô, dì     │ Is she...? │ Cô ấy là cô không? │
│ love     │ yêu, thích │ Do you...? │ Bạn yêu không?     │
│ white    │ màu trắng  │ Is it...?  │ Nó trắng không?    │
│ (tiếp...)│            │            │                    │
└──────────┴────────────┴────────────┴────────────────────┘

NGUYÊN TẮC:
  ✓ Hàng 1: Header (Word, Meaning, Example EN, Example VI)
  ✓ Hàng 2+: Dữ liệu
  ✓ Không để ô trống (cột A)
  ✓ Dữ liệu dây đặc (không dòng trống)
  ✓ Lưu .xlsx (Excel 2016+)
  
  ✗ Không dùng .xls
  ✗ Không để ô trống quan trọng

✅ • Kiểm tra đường dẫn
